# SocialEvents 🌍

**Live Site URL:** social-event-website-frontend.vercel.app

## About The Project
SocialEvents is a full-stack social event management platform designed to connect communities. It empowers users to easily discover, create, and participate in local social service activities like cleanups, blood donations, and health camps. 

## Key Features

* **Secure Authentication:** Fast and reliable user registration, login, and protected routing powered by Better Auth.
* **Dynamic Event Discovery:** A smart "Upcoming Events" feed that automatically filters out past events and sorts them so the most immediate opportunities appear first.
* **Create & Manage Events:** A dedicated private dashboard allowing logged-in users to easily create new events, update details via a modal, and delete their own postings.
* **One-Click Volunteer Tracking:** Seamlessly join community events with a single click and track all your commitments in a personalized "Joined Events" dashboard.
* **Modern & Responsive UI:** Built with Next.js, Tailwind CSS, and DaisyUI to ensure a beautiful, fast, and fully mobile-friendly experience on any device.
* **Decoupled Architecture:** Operates on a robust Express.js backend integrated with MongoDB Atlas for secure, real-time database management.

## Tech Stack
* **Frontend:** Next.js, React, Tailwind CSS, DaisyUI
* **Backend:** Express.js, Node.js
* **Database:** MongoDB Atlas
* **Authentication:** Better Auth
